## 2. 最终链路（唯一，不得新增第二套）

```
PDF
 ↓
Parser
 ↓
Object Tree
 ↓
SelectionState（Primary）
 ↓
EditingSession → EditingCommit
 ↓
FontPatch
 ↓
ContentPatch
 ↓
Save Pipeline → Incremental PDF
 ↓
Parser（回归验证）
```

## 3. 三条长期铁律（不得漂移）

1. **Object 永不直改 PDF**：必须 `lopdf → Parser → ObjectMapper → Object Tree`；写回统一走 `ContentPatch` → Save，Save 不调 Mapper。
2. **每个流程只有一个真值源**：Document（内容）/ Session.selection_state（对象选择）/ ObjectTree（对象）/ FontRegistry（字体）/ PageIndexCache（空间索引）。
3. **Patch 是一次性中间产物**：`EditingCommit` / `FontPatch` / `ContentPatch` 不进 History、Snapshot、持久化，Save 后释放。

## 4. 不变量清单（已实测）

- Unknown Operator 全链路 100% 保留（解析 → 重写 → 写盘 → 再解析）。
- 非目标 Operator 顺序完全不变。
- 跨重新 Parse：ObjectId / BBox / kind / z_index 稳定。
- 版本一致性依据 `Object.version`，禁止 Hash。
- 缩放 / 滚动 / Hover / Selection 不重建空间索引。
- 提交才产 Diff；撤销走 Diff 回放；Patch 不参与撤销。

## 6. 冻结后约束

1. **不再新增编辑相关能力**：Text / Image / Path / Annotation / Form 的进一步编辑若确需扩展，必须走 R2.0 拍板，不得在 18 章内追加。
2. **稳定基础设施**：Parser、Mapper、HitTest、Selection、Editing、Font Rewrite、Content Rewrite、Save Pipeline 供 19 OCR、20 Annotation、21 AI 直接复用。
3. **CI 必跑**：18-09 的 189 条测试作为后续版本的回归基线，任何底层改动不得使其下降。

## 7. 当前已知限制（冻结不等于无限制）

- 真实字体子集字节未生成，Font Embed 未实现。
- Save 后重新 Parse 的 `glyphs` / `version` / `unicode` 为重新派生值，不作为 RoundTrip 判据。
- UI / Desktop 未接入对象编辑链（本次未改 UI）；端到端验证在 Rust 层完成。
- `ObjectMapper::to_content_stream()` 保留兼容 18-03 MT-04，已明确不被 Save 使用；后续不得重新接入。
