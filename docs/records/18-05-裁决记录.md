# 18-05《Selection Engine》架构裁决记录

日期：2026年11月25日
性质：过程记录，仅溯源；规范效力以 `docs/spec/11-Selection-Engine-R1.md` 为准。

---

## 用户四项架构裁决

| # | 裁决 | 落地 |
|---|---|---|
| AD-09 | Selection 真值源保持 Session，不新增 Store、不迁 Workspace | 采用；`Session.selection_state: SelectionState` 为私有字段，只经引擎改 |
| AD-10 | Primary 是 SelectionState 的组成部分，禁止独立 PrimaryManager | 采用；`primary` 与 `selected` 同属一个真值对象，不变量由 `normalize()` 强制 |
| AD-11 | Snapshot 是值对象，不能反向修改 SelectionState | 采用；`SelectionSnapshot` 只读导出，恢复走整份覆盖 |
| AD-12 | Selection 与 HitTest 解耦 | 采用；引擎零 HitTest 调用，失效只返回 `needs_rehit` |

## 主理人冲突裁决（与 18-01 ~ 18-04 既有冻结的冲突）

| # | 冲突 | 裁决 |
|---|---|---|
| C-1 | 18-01 冻结 `Selection` 双轨（`pages` + `objects`），18-05 要求 `SelectionState` 为对象选择唯一真值 | **删除 `Selection.objects` 轨道**及 `objects()` / `objects_is_empty()` / `replace_objects()` / `toggle_object()` / `clear_objects()` 五个方法。已 grep 全项目确认无外部调用点（仅 selection.rs 自身与其单测）。对象选择全部迁入 `SelectionState.selected`。`Selection.pages` 保留——它是**页选择**（Feature-02 页管理语义），与对象选择维度不同，不构成「第二套选择状态」 |
| C-2 | 「四」只给 2 个语义字段，「十二」要求记录两个版本号，验证还需知道是哪一页 | `SelectionState` 实际 4 字段：`page_id`（版本校验作用域）+ `primary` + `selected`（两个语义字段）+ `version: SelectionVersion`（收纳 `page_version` / `index_version`） |
| C-3 | 「十二」说「失效则重新 HitTest」，但 AD-12 与约束 6 说「Selection 不调用 HitTest」 | 引擎只做版本比对 + 失效剔除，返回 `SelectionValidation::Invalidated { needs_rehit }`；**重新 HitTest 由上层 Controller 执行**，结果回送。引擎零 HitTest 调用 |
| C-4 | 「十二」要求 `page_version`，但 `Page` 是 18-01 冻结的 7 字段，新增字段会改变 `PartialEq` 与 Document 快照比较语义 | **不新增 `Page.version` 字段**，改为 `Page::version()` 派生：对 `(object_id, object.version, lifecycle)` 做 FNV-1a 折叠。确定、无存储、不改 `PartialEq`。代价 O(n)，只在验证时计算，不在鼠标移动热路径 |
| C-5 | 「十五」要求 Selection 支持 Undo/Redo，但 `History` 只记 Diff，Selection 变更无 Diff | 撤销走独立 `SelectionHistory`（Snapshot 栈，深度上限 100），**不进 `ExecutionGraph`、不产 Diff、不写 `History`** |
| C-6 | 「九」六个命令与执行链的关系未定 | Selection 命令不产生 PDF 变更，**不进执行链**：不经 `build_tasks()`、不过 `Capability Gate`、不建 `ExecutionGraph`，由引擎同步执行且为唯一修改入口 |

## 补充裁决

- `index_version` 由 `SpatialIndex.version` 提供（`insert` / `remove` / `clear` / `rebuild` 递增），经 `PageIndexCache::version(page_id)` 读取；属 `10` AD-08 的运行时优化，不持久化。
- 引擎公开方法一律收 `&mut Session` 而非 `&mut SelectionState`：`Session::selection_state_mut()` 保持 `pub(crate)`，UI 层在类型上就拿不到可变状态，从结构上落实约束 5（UI 不得直接修改）。
- `EventBus` 不归引擎所有（与 TaskManager 同规则），由调用方传入；`Event` 新增可选 `payload` 字段承载 `SelectionChanged` 的 old/new，纯通知类事件仍为 `None`。

## 遗留边界（不在本章范围）

`ExecutionContext.selection` 仍是 `&Selection`（页选择）。18-01 冻结的 8 字段契约本章**未改动**。若 18-06 需要在 Task 内读对象选择，应经 `Session.selection_state()` 获取，或按 R1.1 另行增补字段，不在本章自行变更。
