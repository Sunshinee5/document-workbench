## 3. AD-08 最终冻结版逐条核验

| 冻结条款 | 代码事实 |
|---|---|
| `Page` 不持有任何空间索引或运行时缓存 | `crates/dw-core/src/page.rs` 字段仅 `page_id` / `page_index` / `rotation` / `size` / `crop_box` / `media_box` / `objects`；grep `index\|cache` 只命中页码相关符号，无索引字段 |
| 索引物理存放 `PageIndexCache`，以 `page_id` 键控 | `PageIndexCache { pages: RwLock<HashMap<PageId, Arc<RwLock<SpatialIndex>>>> }`，键类型即 `PageId` |
| 禁止 `Object → Index` 引用 | `Object`（`object.rs`）无索引字段；`SpatialIndex.objects` 是**单向**持有（Index → Object），对象侧零引用 |
| 禁止 `Page → Index` 引用 | `Page` 无 `SpatialIndex` / `PageIndexCache` 字段，只有 `page_id` 作为外部键 |
| 失效白名单：Object 新增 / 删除 / BBox 改变 / 页面关闭 / Document 释放 | `update_object()`（新增与 BBox 改变）、`remove_object()`（删除）、`invalidate()`（页面关闭 / Document 释放）三个入口，无第四种 |
| 黑名单：缩放 / 滚动 / Hover / Selection 不得重建 | `hit()` / `hit_all()` / `hover()` / `drag_begin()` 全部为只读路径，仅 `get_or_build()`；`zoom` / `screen_position` 只进 `CoordinateConverter`，不参与索引键。测试 `ad08_zoom_scroll_hover_never_rebuild_index` 以 `Arc::ptr_eq` 断言 6 档缩放 + 200 次鼠标移动 + 100 轮 Hover/Selection 后句柄地址不变 |

## 4. 功能完成

- `HitTestRequest { page_id, screen_position, zoom, rotation }` 唯一输入。
- `HitResult` 由 4 字段扩为 6 字段（+`distance` +`priority`），JSON 可往返。
- 管线：`Screen → CoordinateConverter → SpatialIndex → Candidate → BBox Test → Priority Resolver → HitResult`。
- `SpatialIndex`：均匀网格（默认 64pt 格），格子只存 `ObjectId`，超 256 格的大对象进 `oversized` 集合避免撑爆网格；非法 BBox 与已删除对象在 `insert()` 阶段丢弃；`validate()` 提供完整性自检。
- `ObjectPriority`：`Text 50 > Annotation 40 > Image 30 > Form 25 > Path 20 > Unknown/Future 10`，`with_override()` 可覆盖。
- 多命中：`hit_all()` 按 `(priority↓, distance↑, z_index↓, object_id↑)` 四关键字确定性排序。
- 旋转：`HitTestRequest.rotation` 在入口做逆旋转，**未修改** `CoordinateConverter` 的字段与双向可逆契约。
- 18-01 的 `hit_test()` / `hit_test_page()` 线性回退入口保留，契约不变。

## 7. 已知限制

1. **构建环境回归（重要）**：本次清理 `/tmp/dwbuild` 时连带删除了此前预编译的 `chrono` 产物；本机 `windows-gnu` 工具链的 self-contained 目录只有 `ld.exe`，**缺 `as.exe`**，导致 `chrono 0.4.45` 的 `raw-dylib`（经 `windows-link`）无法生成导入库。为恢复回归验证，临时目录内执行 `cargo update -p chrono --precise 0.4.38`（该版本走 `windows_x86_64_gnu` 预编译导入库，不需要 dlltool + as）。**仓库 `Cargo.lock` 未改动**，chrono 与本次改动无关（仅 lopdf 的日期解析使用）。后果：本机从零构建仓库原锁文件会失败，需补 binutils 或把 chrono 锁到 0.4.38。
2. `HitTestRequest` 不携带滚动偏移：滚动由视口承担，`CoordinateConverter` 的 `scroll_x/scroll_y` 在命中路径按 0 传入。若后续 UI 需要页内滚动命中，需在 `10` 补一条 R1.1 字段（不改架构）。
3. `SpatialIndex` 采用均匀网格而非 RTree/QuadTree：`10` §六 允许「建议 RTree 或 QuadTree」，网格在 10000 对象下候选 < 50、1000 次命中 < 5s，满足 §十一 实时要求；如需换成 RTree 只替换 `SpatialIndex` 内部，`PageIndexCache` 与引擎契约不变。
4. `Form` / `Future` 在 `10` §八 未给排名，实现按 `Form 25`（Image 与 Path 之间）、`Future 10`（与 Unknown 同级）扩展，已注明可通过 `with_override()` 覆盖。
5. 旋转只支持 0/90/180/270；非该四值退化为不旋转，不产生 NaN。
