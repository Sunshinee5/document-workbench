## 6. 已知限制

1. **重新 Parse 后 `glyphs` / `version` / `unicode` 不沿用内存值**：Parser 从新内容流重新派生，`version` 回到默认值。RoundTrip 判据已在规范 C-3 收紧为四项跨 Parse 稳定字段。
2. **文本编码按 big-endian u16（Identity-H 风格）**：WinAnsi / MacRoman 的字形字节宽度未分别处理；源 PDF 若带 ToUnicode，写盘后需由上层同步更新映射，本章不处理。
3. **`/Contents` 形态支持有限**：单个 Reference 与 Reference 数组；内联 Stream 不支持（报中文错误）。
4. **增量可用性依赖 `Document.metadata.file_size`**：调用方须回填；否则判为外部改写并回退全量（IT 测试已回填）。
5. **构建环境**：本机 windows-gnu 缺 `as.exe`，TEMP 副本内仍用 `chrono 0.4.38` 规避 `raw-dylib`（仓库 `Cargo.lock` 未改，同 18-04 报告第 7 节第 1 条）。
