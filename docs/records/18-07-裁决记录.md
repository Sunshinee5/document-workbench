# 18-07《Font Rewrite Engine》架构裁决记录

日期：2026年11月25日
性质：过程记录，仅溯源；规范效力以 `docs/spec/13-Font-Rewrite-Engine-R1.md` 为准。

---

## 用户四项架构裁决

| # | 裁决 | 落地 |
|---|---|---|
| AD-17 | FontRegistry 唯一字体真值 | 采用；`Document.font_registry`，`Object` 只持 `FontRef` |
| AD-18 | Glyph 属于 Font Rewrite | 采用；引擎产出 Glyph 只进 `FontPatch.glyph_mapping` |
| AD-19 | Font Rewrite 不修改交互状态 | 采用；`rewrite()` 签名只有 `commit` / `registry` / `events` |
| AD-20 | FontPatch 为唯一输出 | 采用；不改 Document、不写 PDF，由 18-08 消费 |

**编号一致性**：本章 §三～§六 与 §十七 的 AD-17~20 定义完全一致，**不存在 18-06 那种编号重复问题**。

## 主理人冲突裁决

| # | 冲突 | 裁决 |
|---|---|---|
| C-1 | **AD-18「Object 禁止保存 Glyph Index」与 18-01 冻结的 `TextObject.glyphs: Vec<u32>` 直接冲突**：后者是 Parser 从内容流解析出的原始编码，18-02/18-03 Round Trip 依赖它 | **保留字段，不改 18-01/18-03 结构**。重新定义语义：`glyphs` 是 Parser 产出的**只读原始编码**；Font Rewrite **永不写回**，其产出只进 `FontPatch.glyph_mapping`。引擎只收 `&Object`，类型上无法修改 |
| C-2 | §六「Save 统一消费 Patch」 vs §十六/§十八「由 18-08 消费」 | 统一 **18-08 是 FontPatch 唯一消费者**；Save 消费 18-08 的输出。Save 不直接吃 Patch，否则本章侵入写盘链 |
| C-3 | AD-17 要 Document 持有 Registry，AD-20 又禁止引擎修改 Document | 引擎只收 `&FontRegistry`；注册由调用方 / Parser 完成，本章只提供数据结构与 `insert()` |
| C-4 | §八查表失败要 `MissingGlyph`，§九又要 `ValidationFailed` | 结构合法性 → `ValidationFailed` / `FontNotFound` / `EncodingUnsupported`；cmap 查不到具体字符 → `MissingGlyph` |
| C-5 | Unicode Normalize 需要 NFKC，但 dw-core 无规范化依赖，05 禁止核心库引第三方业务库 | 实现**确定性最小规范化**：trim + 全角 ASCII（FF01–FF5E）折半角 + 全角空格 U+3000→空格。**不是完整 NFKC**，缺字形严格报错 |
| C-6 | `FontRef` 无 `Ord` / `Hash`，不能作 `BTreeMap` / `BTreeSet` 键 | 补派生 `PartialOrd, Ord, Hash`（R1.1 派生补充，不改字段、不改身份语义） |
| C-7 | 「暂不生成 Subset Font」下 `added_fonts` / `removed_fonts` 语义不明 | `added_fonts` = `NewSubset` 策略时需 18-08 新建的字体引用；`removed_fonts` 本章恒空 |
| C-8 | AD-17「Registry 是 Document 真值」与 AD-20「Patch 独立于 Save」的张力 | Registry 是**长期真值**（Document 字段）；Patch 是**一次性规划输出**（不进 `DocumentSnapshot`、不持久化）。两者正交 |

## 补充裁决

- `TextObject.glyphs` 的文档注释已补上 C-1 的语义说明，但字段与类型不变。
- `FontDescriptor.cmap` 的键统一走 `normalize_unicode()`，与引擎查表键一致，避免「规范化前后键不匹配」的假 MissingGlyph。
- `FontRewriteEngine` 无状态（`struct FontRewriteEngine;`），可全局复用；不持有 EventBus，由调用方传入。

## 遗留边界（不在本章范围）

1. 不生成真实 Subset Font 字节（§九明确"暂不真正生成"），Font Embed 属禁止项。
2. `FontRegistry` 不进 `DocumentSnapshot` / Save / Recovery：本章不做字体资源持久化，写盘由 18-08 + Save 链负责。
3. 18-08 唯一输入冻结为 `EditingCommit + FontPatch`，不得重新解析字体。
