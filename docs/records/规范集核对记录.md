## 四、本轮暴露的方法问题（供后续参考）

1. **编号必须带前缀**。三份文档各有一套 `D*`/`E*`/`S1-*`，跨文档引用必须写「`02` D1」而非「D1」。裸写编号是静默错误的主要来源。
2. **「禁止清单的完整版」必须真完整**。00 §11 说「完整版见 05」，但 05 漏了 3 行（含一条全篇零命中）——**指针式规范最怕目标文档不全**。
3. **同一份文档内部也会打架**。05 的 F11 与 F2、F7 口诀与 checklist、F10 与 R13，三对都在同一文件内。核对不能只做跨文档比对。
4. **验证命令会随方案失效**。批了「加交叉引用」之后，「grep 应为空」的验证命令就不再适用，要改成「查裸写」。
5. **规范里的正例比禁令更容易出错**。禁令写「禁止 X」很少写错，但「正确写法」举错例子，Agent 会照着错例写——F11 就是这种情况。
