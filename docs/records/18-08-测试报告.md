## 7. 已知限制

1. **CT-11 不是真正写盘集成**：按 C-6，本章禁止 Save / Incremental Save；端到端写盘归 18-09。
2. **`ObjectMapper::to_content_stream()` 仍存在**：为兼容 18-03 MT-04 而保留，已明确不再作为 Save 的 Operator 来源；18-09 集成时须确认无旁路调用（C-5）。
3. **文本重写只替换字形字节**：不改 `Tf` / `Tm` / `Td`，不生成子集字体，不做 Font Embed。真实字体字节仍待上层处理。
4. **字形按 big-endian u16 编码**：适配 Identity-H 风格；其它编码（WinAnsi / MacRoman）的字形字节宽度尚未按编码分别处理。
5. **Unknown 判定基于已知 Operator 白名单**：白名单只用于校验，不影响透传；lopdf `Content::decode()` 遇到无法识别的Operator 名（含非字母字符）本身会解析失败，这是第三方解析器限制，18-02 已有逐行降级补偿。
6. **构建环境**：本机 windows-gnu 缺 `as.exe`，TEMP 副本内仍用 `chrono 0.4.38` 规避 `raw-dylib`（仓库 `Cargo.lock` 未改，同 18-04 报告第 7 节第 1 条）。
