## 1. 功能完成列表

**已实现（纯数据模型 + 纯计算）**
- `ObjectId` 稳定标识 + `ObjectIdAllocator`（不依赖渲染/坐标，单调递增）。
- `ObjectKind { Text, Image, Path, Annotation, Form, Future }`。
- `ObjectLifecycle { Created, Loaded, Modified, Deleted }`（用户冻结项一）+ `Object.version`（冻结项二）。
- `BBox`（PDF 坐标真实边界，含 contains / intersects / area / center）。
- `TextObject`（glyphs + unicode 双存）/ `ImageObject` / `PathObject` / `AnnotationObject` / `FormObject`。
- `ObjectPayload` 扩展枚举；统一 `Object` 结构（`lifecycle` + `version` + `payload`）。
- `Page` / `PageId`（原始页码 newtype）+ `Size` / `Rect`；`Page.objects: BTreeMap<ObjectId, Object>`。
- `PdfPoint` / `ScreenPoint` / `CoordinateConverter`（可逆往返，纯计算）。
- `HitResult` + `hit_test` / `hit_test_page`（按 z_index 取最上层）。
- `Selection` 双轨：`pages: Vec<u32>` + `objects: Vec<ObjectId>`，互不干扰。
- `Capability::ObjectEditing`（与 `Edit` 并存，PDF 声明两者）。
- `ObjectDiffPayload` + `Diff::object_change()`（装入 StructureDiff.payload，不新增 Diff 顶层变体）。
- `ObjectMapper` 骨架（`to_lopdf` / `from_lopdf` 返回明确中文「待 18-02」，不 panic）。

**明确未实现（规范 §二十一）**
- Text Editing / Font Rewrite / Content Stream Rewrite / OCR / 任何 IPC / 任何 UI / 任何实际编辑 Command 或 Task。
- 对象级 Diff 的实际回放（18-02 起）。
- ObjectMapper 的真实映射（18-02 / 18-03）。

## 5. 已知限制

1. **对象级 Diff 回放未实现**：`ObjectChange` 分支返回明确中文错误「待 18-02」，数据与序列化已完整可测。
2. **ObjectMapper 为骨架**：`to_lopdf` / `from_lopdf` 返回「待 18-02」，接口签名与错误语义已冻结。
3. **HitTest 仅纯几何**：无鼠标事件管线、无屏幕坐标自动换算（Engine 归 18-04）。
4. **未解析真实 PDF**：Parser 归 18-02；本章 Object 树由调用方构造。
5. **未跑 `cargo tauri build` 与完整 workspace clippy**：本次未改 `dw-desktop` / UI；前端未改，沿用 17 的 `npm run build` PASS 结论。
6. **环境限制**：本机 cargo 并发编译存在文件锁冲突（`os error 5`），必须 `-j 1` 单线程；这是环境问题，非代码缺陷，已如实记录。

## 6. 风险

- 嵌套 Pages 树解析兼容性依赖 18-02 的 Parser 实现，本章未覆盖真实 PDF。
- `Object.version` 目前由 `mark_modified()` 维护，18+ 编辑入口必须统一走它，否则 version 不单调。
- `Selection` 双轨中 `objects` 尚未接入 IPC/UI，属 18-05 范围。
