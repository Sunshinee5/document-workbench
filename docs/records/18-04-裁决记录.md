## AD-08 最终冻结（用户 2026-11-25 正式版，替换主理人初稿）

用户确认并强化：`Spatial Index` 的生命周期由 Page 驱动，但物理存放于 HitTest 模块的 `PageIndexCache`，以 `page_id` 为键管理。**`Page` 不持有任何空间索引或运行时缓存。**

**架构关系**：
```
Page (dw-core) ──page_id──▶ PageIndexCache (HitTest) ──▶ Spatial Index
```
禁止 `Object → Index` 与 `Page → Index` 直接引用。

**生命周期**：Page Created → Create Index / Page Modified → Invalidate Index / Page Removed → Destroy Index。Index 数据始终只在 PageIndexCache，可随时重建，不持久化。

**失效规则（仅这些情况，其余不得重建）**：✅ Object 新增 / Object 删除 / Object BBox 改变 / 页面关闭 / Document 释放；❌ 缩放 / 滚动 / Hover / Selection。Index 只存 PDF 坐标 BBox，与缩放无关。

**职责**：Page = 领域真值；PageIndexCache = 运行时优化；HitTest Engine = 消费缓存。Save / Recovery / Undo 不受缓存影响。

## 主理人初稿裁决（已被上面正式版替换，仅留溯源）

初稿曾裁决「Index 生命周期属 Page、物理放 PageIndexCache」，与用户最终版方向一致；用户正式版追加了**禁止反向引用**与**缩放/滚动/Hover/Selection 不得重建**两条硬规则，并以 `page_id` 为唯一缓存键。以正式版为准。
