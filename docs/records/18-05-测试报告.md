## 4. 功能完成

- `SelectionState`：唯一真值，三条不变量由 `normalize()` 强制（primary 属于 selected；空集清 primary 与 page_id；primary 非法时落集合最大者）。
- `SelectionSnapshot`：`page_id` / `primary` / `selected`，可 JSON 往返，只读。
- `SelectionPolicy`：`Single` / `Multi` 生效；`Rectangle` / `Lasso` / `Text` 仅冻结接口，调用返回 `SelectionError::PolicyNotImplemented`，**不静默降级**。
- `ModifierKeys`：Ctrl 切换、Shift 追加、Alt 保留；无修饰键替换。
- `SelectionCommand`：`Select` / `Toggle` / `Add` / `Remove` / `Clear` / `SelectAll`。
- `SelectionChange` + `EventPayload::Selection`：`SelectionChanged` 携带 old / new 结构化载荷；无实际变化时不发布。
- 版本一致性：`page_version` + `index_version` 双记录；仅版本漂移而内容有效时刷新版本不发布事件；内容失效时剔除并重选 primary。
- 生命周期：`attach_document()` 切文档清空并发布；`detach()` 销毁并清空撤销栈。
- 错误：`PolicyNotImplemented` / `ObjectNotFound` / `PageMismatch`，均为中文 `Display`。

## 7. 已知限制

1. **`Selection.pages` 与 `SelectionState` 并存**：前者是页选择（Feature-02 页管理），后者是对象选择。两者维度不同，已由 C-1 说明；若后续要合并，需 R2.0 拍板。
2. **`ExecutionContext.selection` 仍是 `&Selection`**：18-01 冻结的 8 字段契约本章未动。18-06 若需在 Task 内读对象选择，走 `Session.selection_state()` 或按 R1.1 增补。
3. **`page_version` 是 O(n) 派生值**：10000 对象页每次验证约一次全表折叠。只在对象变更 / 索引重建后调用，不在鼠标移动热路径；若后续成为瓶颈，可改为 Page 上缓存字段（需 R1.1 字段增补）。
4. **`needs_rehit` 只给信号**：重新命中由上层 Controller 执行，本章不提供「自动重命中」封装（AD-12 约束）。
5. **撤销栈深度上限 100**：超出丢最旧一条，与 `CheckpointStore.INTERVAL = 100` 同量级，未做配置化。
6. **构建环境**：本机 windows-gnu 缺 `as.exe`，TEMP 副本内仍用 `chrono 0.4.38` 规避 `raw-dylib`（仓库 `Cargo.lock` 未改，同 18-04 报告第 7 节第 1 条）。
