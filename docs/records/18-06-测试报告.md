| 裁决 | 落实情况 |

## 4. 功能完成

- `EditingSession`：`object_id` / `original_version` / `working_copy` 三字段，与冻结一致。
- `EditingState`：`Idle` / `BeginEdit` / `Editing` / `Commit`，非法迁移一律拒绝。
- `EditingOperation`：`ReplaceText` 生效；`Insert` / `Delete` / `Style` 冻结接口，返回 `PolicyNotImplemented`。
- Validation 四检：Object Exists → Version Match → Selection Match → Capability Check，任一失败不写页面。
- `VersionConflict { expected, actual }`：编辑期间对象被外部改动即拒绝，**不覆盖**。
- `EditingCommit { object, diff, before_version, after_version }`。
- 事件：`EditingStarted` / `EditingCommitted` / `EditingCanceled`，均带结构化载荷。
- 对象级 Diff 回放：`Diff::apply_object(&mut Page)` / `Diff::revert_object(&mut Page)`。

## 7. 已知限制

1. **ReplaceText 不改变 PDF 页面显示**：本章只改对象模型（`TextObject.unicode`），字形/字体子集重写归 18-07，内容流重写归 18-08。这是章节边界，不是缺陷（`12` C-9）。
2. **Mapper 步骤不在 dw-core**：`dw-core` 不能依赖 `dw-pdf`，Commit 只产出可映射对象；`ObjectMapper::to_intermediate()` 由上层在 dw-pdf 侧调用（`12` C-2）。
3. **对象级 Diff 只能对 Page 回放**：`Diff::apply(&Document)` 遇 `ObjectChange` 明确报错，因为 `Document` 只持 `PageLayout`、不含对象树（`12` C-4）。
4. **Undo 会把 version 退回去**：回放必须与 Diff 对称；单调性只约束编辑动作（`12` C-5）。
5. **EditingSession 不持久化**：崩溃后未提交的 WorkingCopy 丢失，符合 AD-13 与「事务未提交即不生效」。
6. **构建环境**：本机 windows-gnu 缺 `as.exe`，TEMP 副本内仍用 `chrono 0.4.38` 规避 `raw-dylib`（仓库 `Cargo.lock` 未改，同 18-04 报告第 7 节第 1 条）。
