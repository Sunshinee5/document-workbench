# Document Workbench 验收清单（R1）

> 本清单是人工层的固定检查表，与 `tools/verify.ps1`（自动层）配套。
> 每个 Feature 提交前逐项勾选；不能自动化的项目由 Reviewer 对照截图现场验收。
> 规范依据：`docs/features/16-Feature-03-History-Undo-Redo.md` §二十二。

## 第 1 层 · 编译（自动）

- [ ] `tools/verify.ps1` 输出 `RESULT: PASS`
- [ ] 格式检查 / 静态检查 / 全量测试 / 前端构建 / Tauri Debug 构建全通过
- [ ] 失败则直接退回，不做功能测试

## 第 2 层 · 启动（人工）

- [ ] 连续启动 10 次，主窗口每次都显示
- [ ] 菜单、工具栏、Viewer 初始化正常
- [ ] `logs/YYYY-MM-DD.log` 有启动 INFO
- [ ] 无崩溃 / Panic / 白屏 / Renderer Error

## 第 3 层 · Feature（人工）

### 14 PDF Viewer
- [ ] 打开 PDF → 第一页显示 → 滚轮滚动 → 缩放 → 跳页 → 关闭

### 15 Page Editing
- [ ] 旋转 90° / 180° / 270°
- [ ] 删除页（至少保留一页）
- [ ] 移动页 / 拖拽排序

### 16 History
- [ ] Rotate → Undo → Redo
- [ ] Delete → Undo → Redo
- [ ] Move → Undo → Redo

## 第 4 层 · 异常（人工）

- [ ] 打开损坏 PDF → 返回 `DwError`，不 Panic
- [ ] 打开密码 PDF → 中文提示，不 Crash
- [ ] 删除最后一页 → 拒绝，Document 不为空

## 第 5 层 · 边界（人工）

- [ ] 页数 1 / 10 / 100 / 1000 / 5000 分别打开
- [ ] 文件 500KB / 20MB / 300MB 分别打开
- [ ] 连续 Undo 100 次 / Redo 100 次
- [ ] 连续 Rotate 1000 次不崩

## 第 6 层 · 一致性（人工）

- [ ] Rotate 后 Viewer / Thumbnail / Workspace / Document / History 五处一致
- [ ] Delete 后 PageCount / Thumbnail / Selection / CurrentPage 同步

## 第 7 层 · 事务（人工，最重要）

- [ ] 3 个 Task 的 Command 中第 2 个失败
- [ ] History 无记录
- [ ] Document / Workspace 全部恢复，无半成功状态

## 第 8 层 · 性能（记录基线）

- [ ] 1000 页 PDF：启动时间 / 打开时间 / 第一页时间 / 内存
- [ ] 100 页旋转：耗时

## 第 9 层 · 日志（人工）

- [ ] Open → Rotate → Undo → Redo → Close 全过程日志完整
- [ ] 日志中无 ERROR（故障注入测试除外）

## 第 10 层 · Release（人工）

- [ ] Debug 与 Release 绿色版分别双击启动
- [ ] 打开 PDF → 关闭 → 再次启动全部 PASS
