## 二、冻结理由

前九章架构设计事实上已围绕 Rust 展开：Driver、Runtime、lopdf、Cargo Workspace、Rust Trait、Tauri IPC、Rust 生命周期、Rust FFI 全部是 Rust 思维。此时改 Qt 不是换 UI，而是推翻整个 Runtime。

真正复杂的不是 UI 而是 Runtime，Runtime 已有 90% 是 Rust。为剩下 10% 换 Qt 没有意义。

AI Agent 维护 Rust 比维护 Qt C++ 更容易：错误确定、生命周期明确、Cargo 统一、现代 AI 训练数据更多。
