# 规范 26 · V1.0 收官阶段（一）UI 完善与现有能力接入实施规范（Agent执行版）

Version：R1.0  
Status：Implementation Freeze  
Compatible with：Architecture Freeze **R1.1**  
Depends：`18` / `19` / `20` / `21` / `22` / `23` / `24` / `25`

> **本文不是 RFC，不新增任何架构。**  
> 本文唯一目的：**把 18~24 已实现（或已冻结）的能力完整映射到 Desktop UI。**  
> 本阶段属于 **V1.0 收官实施**。

禁止：

- 新增 Manager
- 新增 Store
- 新增 Framework
- 新增 Runtime
- 新增 IPC 体系
- 新增第二套 UI
- 修改 Editing Engine
- 修改 Save Pipeline
- 修改 OCR Pipeline
- 修改 Search Framework
- 修改 AI Framework
- 修改 Plugin Framework
- 推翻 18~24 冻结设计

全部建立在既有平台之上。

---

## 一、目标

完成以后，不是：

> 后端有能力，UI 没有入口。

而是：

> 所有能力都有对应 UI。

原则：

**功能 100% 映射。**

不是新增功能。

---

## 二、总体原则

UI 只负责：

- 展示
- 操作
- 状态反馈

所有业务继续走：

- Core
- Desktop
- IPC

禁止 UI 写业务。

---

## 三、本阶段工作

划分为四部分：

1. UI Polish
2. 已实现能力接入
3. Desktop 体验
4. 测试

# 第一部分 UI Polish

## 1. Ribbon

当前 Ribbon 高度过大，调整为：

- 高度：90~96 px
- Icon：32 px
- 文字：12 px
- Group：统一间距

禁止不同按钮不同高度。

## 2. Quick Access

Ribbon 左上增加 Quick Access，固定包含：

- 保存
- 撤销
- 重做
- 打开

## 3. 左侧导航

当前只有图标。要求 Hover 显示 Tooltip，覆盖：

- OCR
- Annotation
- Search
- AI
- Plugin
- Settings

支持 Collapse。

## 4. Dashboard

未打开 PDF 时禁止整页空白，改为 Dashboard。内容包含：

- 最近文件
- 继续编辑
- 最近 OCR
- 最近 AI
- 最近搜索
- 示例文档
- 拖入 PDF
- 新建
- 打开

## 5. Property Panel

统一布局顺序：

```text
Document
  ↓
Page
  ↓
Selection
  ↓
Object
  ↓
OCR
  ↓
Annotation
  ↓
Search
  ↓
AI
  ↓
Plugin
  ↓
Debug
```

无数据时显示 Placeholder。

## 6. StatusBar

重新布局：

- 左：Page / Zoom / Selection / Mode
- 中：Save / OCR / Search / AI
- 右：Memory / CPU / Scale

## 7. Theme

统一 Fluent Design：

- 颜色
- 图标
- 按钮
- 间距
- 阴影
- 动画

不要混搭。
